# ADR-0006：首版 `verified_at` 是种子值

- 状态：已接受（临时，2026-10-31）
- 背景：首版 9 条需要一个可运行的注册表。`verified_at` 先取自各仓库最后一次提交日（2026-10-20），用于把 schema、生成器和站点链路跑通；这**不等于**维护者当天重跑过判据。
- 决策：在 `v0.1.0` 公开发布前，维护者逐条重跑判据并更新 `evidence.verified_at`；在那之前，README 与站点上的「验证于」只代表种子日期。
- 后果：
  - 不要把首版日期当成对外承诺；发布 checklist 必须包含「逐条重跑并更新」。
  - `npm run stale` 仍会在 90 天后提醒，但提醒不能替代发布前复核。
  - 复核完成后删除本条 ADR 的「临时」状态，并在 release notes 里写明。
